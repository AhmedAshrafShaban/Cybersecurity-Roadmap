## 🌐 Track 2 — Network Penetration Testing

<details open>
<summary><b>Click to expand / collapse</b></summary>

```
Reconnaissance → Scanning → Enumeration → Exploitation → Post-Exploitation → Reporting
```

| # | Topic | Key Tools |
|---|-------|-----------|
| 1 | **Network Recon & Port Scanning** | Nmap, Masscan |
| 2 | **Service Enumeration** | SMB · FTP · SSH · RDP · SNMP · LDAP |
| 3 | **Network Attacks** | MITM, ARP Spoofing, Responder |
| 4 | **Password Attacks** | Hydra, CrackMapExec |
| 5 | **Exploitation Frameworks** | Metasploit, Impacket |
| 6 | **Active Directory Attacks** | BloodHound, Kerberoasting |
| 7 | **Privilege Escalation & Lateral Movement** | PowerView, WinPEAS/LinPEAS |
| 8 | **Reporting** | Findings mapped to network segments |
